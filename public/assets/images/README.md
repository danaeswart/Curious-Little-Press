# Images

Drop real photography/artwork in here using the filenames referenced throughout the
app (see each component's `<ImagePlaceholder name="..." />` usage). When a file with a
matching name exists, it replaces the placeholder automatically — no code changes
needed.

- `hero-press.png` — the press illustration next to the hero heading
- `studio-exterior.jpg` — the studio storefront photo in the "What is CLP?" section
- `logo-badge.png` — the round hanging shop-sign badge over the storefront photo
- `workshop-join.jpg` — "Join a Workshop" card
- `workshop-guidance.jpg` — "Work With Guidance" card
- `workshop-edition.jpg` — "Edition Your Work" card
- `workshop-independent.jpg` — "Work Independently" card
- `map.jpg` — the round map graphic in the contact section

Add more as new pages (gallery, service detail pages, etc.) are built out.
